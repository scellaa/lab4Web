This project is a simple website layout created using HTML and CSS. It demonstrates the basic structure of a website, including a header, navigation bar, hero section, main content, sidebar widgets, portfolio cards, and footer.

Explanation step by step:

This step demonstrates the implementation of the sidebar widgets in the website layout. The sidebar consists of two sections: "Widget Header" and "Widget Text." The Widget Header section contains five links that can be used to navigate to other content, while the Widget Text section displays a paragraph of descriptive text. Both sections use blue title backgrounds with white, bold text to distinguish their headings from the rest of the content. The layout is styled using CSS classes such as .widget-box and .title, which control the borders, spacing, and background colors. The footer appears below the content and displays the copyright information for Universitas Pelita Bangsa. This step demonstrates how sidebar widgets and a footer can be incorporated into a website to organize information and improve its overall structure.

This step demonstrates the implementation of the main content section and sidebar in the website layout. The main content area displays three content boxes, each containing a placeholder image, a heading, a short description, and a "View detail" link. These boxes are intended to be arranged horizontally using the `.box` and `.row` CSS classes. On the right side, the sidebar contains two widgets: "Widget Header," which displays a list of five links, and "Widget Text," which contains a descriptive paragraph. The sidebar is styled using the `.widget-box` and `.title` classes to create blue headings, white text, borders, and spacing. The navigation bar and hero section remain at the top of the page, maintaining the overall website structure. This step demonstrates how the main content and sidebar can be combined to organize information within a single website layout.

This step demonstrates the addition of the featurette article sections to the website's main content area. The first article contains a heading, a placeholder image positioned on the left, and a paragraph displayed beside the image. The second article follows a similar structure, but its image is positioned on the right to create a different visual arrangement. These layouts are controlled by the `.entry` and `.right-img` CSS classes, which use spacing and the `float` property to position the images and text. Horizontal divider lines separate the articles and improve the organization of the page. The three content cards and sidebar widgets remain visible above and beside the articles, maintaining the overall website layout. This step demonstrates how CSS can arrange images and text within article sections to create a more structured and readable webpage.

This step demonstrates the development of the About page, which provides information about the website and its purpose. The page begins with the heading "About Us" and a short introduction explaining that the website was created to practice HTML and CSS. The "Our Description" section provides further information about the website's structure and the HTML elements used in its development. Below this, the "Our Portfolio" section displays three cards: Web Development, Programming, and Creative Projects. Each card contains a heading and a brief description of the activities or skills represented. The cards are arranged horizontally using CSS Flexbox, with spacing, borders, rounded corners, and a light background to create a neat appearance. The navigation bar remains consistent with the Home page, while the About link is highlighted to indicate the current page. Finally, the footer displays the copyright information for Universitas Pelita Bangsa. This step demonstrates how to create a separate About page with an organized layout and consistent styling across multiple website pages.

This step demonstrates the development of the Contact page, which allows visitors to send messages through a contact form. The page begins with the heading "Contact Us" and a short instruction asking users to complete the form. The form contains three fields: Name, Email, and Message, allowing users to enter their personal information and write their inquiries. The name and email fields use text inputs, while the message field uses a larger text area to accommodate longer messages. Each field includes a placeholder to guide users on what information to enter. The "Kirim Pesan" button is styled with a dark background, white text, and rounded corners to make it visually distinct. CSS Flexbox is used to arrange the form elements vertically, while padding, margins, and a maximum width help maintain a clean and readable layout. The navigation bar highlights the Contact link to indicate the current page, and the footer displays the copyright information for Universitas Pelita Bangsa. This step demonstrates how HTML forms and CSS styling can be combined to create a simple and user-friendly contact page.
